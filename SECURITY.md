# Política de seguridad

## Versiones soportadas

El proyecto se encuentra en estado alpha. Las correcciones de seguridad se aplican a la versión más reciente de la rama `main`.

## Reportar una vulnerabilidad

No publiques vulnerabilidades potenciales en un issue público. Utiliza **Report a vulnerability** en la pestaña Security del repositorio. Incluye las versiones afectadas, pasos de reproducción, impacto y mitigaciones conocidas.

No incluyas credenciales de Moodle, tokens, datos de producción ni información personal de estudiantes.

## Despliegue

Antes de usar el plugin institucionalmente, deben revisarse roles, capacidades, política de tratamiento de datos y retención del almacén de logs. Valídalo primero en un entorno que no sea de producción.
